# TeeVClean visual system

## Direction

TeeVClean uses a **scan-to-clean** visual language. The TV frame represents the device, the cyan beam represents scanning, amber particles represent removable clutter, and the green sparkle represents a successful cleanup.

## Assets

- `teevclean-brand.svg` — primary launcher mark, favicon source, and compact brand symbol.
- `teevclean-banner.svg` — wide hero/banner artwork for product pages, store listings, and onboarding.

Both files are vector assets and can be exported to PNG at the target Android TV density or used as source artwork for adaptive launcher icons.

## Palette

| Token | Hex | Use |
|---|---|---|
| Graphite | `#101820` | App icon background and primary surfaces |
| Deep screen | `#0D171F` | TV display and elevated dark panels |
| Electric cyan | `#23D9E8` | Scan beam, links, active navigation |
| Neon green | `#8CFF72` | Successful cleanup and primary confirmation action |
| Warning amber | `#FFC857` | Clutter, attention, and caution states |
| Soft white | `#F4FBFF` | Primary text and high-contrast icon details |

## Android TV usage

Keep the visual language high contrast and legible at the 10-foot distance. The green action color should be reserved for the primary focused action or completed state; cyan should communicate active scanning; amber should communicate recoverable clutter rather than danger.
